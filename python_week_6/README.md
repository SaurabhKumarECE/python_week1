# House Price Prediction Using Machine Learning

## Project Overview

This project predicts house prices based on:

* Area
* Bedrooms
* Bathrooms
* Floors
* Parking Spaces

The project uses Machine Learning and Streamlit for deployment.

---

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Joblib
* Streamlit

---

## Project Workflow

1. Problem Definition
2. Dataset Preparation
3. Model Training
4. Model Optimization
5. Integration
6. Testing
7. Deployment

---

* house_price_dataset.csv
